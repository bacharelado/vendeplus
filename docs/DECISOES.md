# Diretrizes executivas — VENDE+

**D1 WhatsApp:** número comercial dos primeiros vendedores confirmado manualmente pelo administrador. Nada de SMS pago. Confirmação da conta e publicação de anúncios são procedimentos distintos.

**D2 Regras:** base inicial no regulamento v0.1; regras e documentos jurídicos devem ser finalizados antes de atender público real. Moderação automática prévia de anúncios apenas depois das verificações; fiscalização posterior e contestação.

**D3 Região:** vendedores declaram vínculo com bairro Poranga II; sem selo oficial nem coleta de endereço residencial completo no piloto.

**D4 Finanças:** orçamento autorizado R$ 0; desenvolvimento local. Serviços gratuitos terão cotas e podem mudar; nenhum upgrade automático ou assinatura sem aprovação do fundador.

**D5 Marca:** VENDE+ é o nome de trabalho escolhido; checar conflitos de marca antes de domínio e divulgação comercial.

**Escopo atual:** vitrine pública sem dados fixos, API de leitura preparada para D1 e rascunhos persistidos no navegador. Publicação online, contas e administração protegida ainda não foram ativadas. Não é um serviço pronto para operação comercial.
